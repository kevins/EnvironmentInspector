Environment Inspector

A tool for Microsoft Dataverse environments. Unmanaged layers finds the components of the managed solutions you choose that have an unmanaged layer on top, shows what changed, and deletes the layers you select. Compare environments compares the components of your solutions, and the changes made in each environment, with a snapshot of another environment. Compare data compares the records of the tables you choose with a data snapshot of another environment. It runs in Edge with your own sign-in; nothing is installed in the environment.

Install

  1. Show the favourites bar (Ctrl+Shift+B).
  2. Drag this button onto the favourites bar: Environment Inspector

If dragging does not work: create a new favourite named Environment Inspector and paste this as its URL.

Use

  1. Open a page of the environment (for example https://contoso.crm.dynamics.com) or its Solutions page in the maker portal (make.powerapps.com).
  2. Click Environment Inspector in the favourites bar.
  3. Unmanaged layers: choose the managed solutions (and, if you like, object types or tables), then Scan. Filter any column, open a component's solution layers or its changes, export, or tick components and select Delete unmanaged layer.
  4. Compare environments: in one environment, choose the solutions and select Save snapshot; in the other, open that file under Compare with and select Compare. Nothing is changed in either environment.
  5. Compare data: the same, with the tables you choose: Save snapshot in one environment, then Compare with that file in the other.

Deleting an unmanaged layer cannot be undone. It is the same as "Remove active customizations" in the maker portal: the component goes back to what its managed solution defines. Each component is checked before and after, and a log of the removed changes can be downloaded.
